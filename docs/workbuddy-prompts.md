# WorkBuddy 测试 Prompt（v2）

> 用途：在 WorkBuddy 里逐条复制运行，记录模型实际调用的工具、参数和最终回答。
> 本文件只提供 prompt，不代表已经运行。
> 模型：DeepSeek V4.1 Flash；MCP：`legal-aid-mcp`；默认 `USE_MOCK=1`、`USE_LIVE=0`。

## 前置

1. 完全退出 WorkBuddy（托盘也退出）再打开。
2. MCP / Connectors 里确认 `legal-aid-mcp` 已启用。
3. 第一次调用批准 5 个工具：`find_legal_service`、`plan_route`、`search_law`、`verify_citation`、`legal_calculator`。
4. 新建对话，模型选 DeepSeek V4.1 Flash。
5. 每条 prompt 单独新建对话，避免上下文互相污染。

## 8 条核心 Prompt

### 1. 单工具 · 找法院

```text
济南市中级人民法院在哪？
```

期望：

- 调用 `find_legal_service(keyword="法院", city="济南")`
- 返回名称、地址、电话、经纬度
- 不应编造电话

### 2. 单工具 · 查法条

```text
违约金过高，法律怎么规定？
```

期望：

- 调用 `search_law(query="违约金过高")`
- 返回民法典第五百八十五条，正文含“违约金”“过分高于”

### 3. 多工具 · 找法援 + 规划路线

```text
我在济南西站，要去济南中院立案，附近有法律援助吗？帮我规划路线。
```

期望：

- `find_legal_service(keyword="法律援助中心", city="济南")`（返回 `{results, coverage, warnings}`）
- `plan_route(origin="济南西站", destination="济南市中级人民法院")`
- 最终回答包含法援机构和路线距离/时间

### 4. 多工具 · 核引用 + 找律所

```text
这份答辩状引用了民法典第 585 条，帮我核对，并找济南的律所。
```

期望：

- `verify_citation(text=...)`，第 585 条 `exists`
- `find_legal_service(keyword="律师事务所", city="济南")`
- 不应把“存在”说成“不存在”

### 5. 参数模糊 · 历下法院

```text
历下法院怎么走？
```

期望：

- 模型能理解为“济南市历下区人民法院”
- `find_legal_service(keyword="法院", district="历下区")`
- `plan_route(...)`
- 如果模型追问“是历下区人民法院吗”，也算合理

### 6. 异常 · 不存在的城市

```text
火星上有法院吗？
```

期望：

- `find_legal_service(keyword="法院", city="火星")`
- 返回 `CITY_NOT_FOUND` 或明确说查不到
- 不编造法院名称/地址

### 7. 无需工具 · 概念解释

```text
什么是违约金？
```

期望：

- **不调用任何工具**
- 直接解释违约金的定义和常见调整规则
- 如果模型调用了 `search_law`，记录为不符合预期

### 8. 伪造引用 · 不存在条号

```text
民法典第 9999 条怎么说？
```

期望：

- `verify_citation(text="民法典第9999条")`
- 返回 `not_found`，明确说该条不存在
- 不编造第 9999 条内容

## 4 条 v2 扩展 Prompt

### 9. 民事诉讼 · 期间

```text
民诉法第 85 条怎么规定期间计算？
```

期望：

- `search_law(query="民诉法第85条")`
- 返回民事诉讼法第八十五条，正文含“期间”“法定休假日”

### 10. 12348 法律援助目录

```text
历下区法律援助中心在哪？电话多少？
```

期望：

- `find_legal_service(keyword="法律援助中心", district="历下区")`
- 返回 `{results, coverage, warnings}`
- 结果 `source` 为 `12348` 或 `snapshot`
- 名称应包含“历下区法律援助中心”

### 11. 诉讼费计算

```text
诉讼请求金额 100 万元，财产案件受理费大概多少？
```

期望：

- `legal_calculator(action="litigation_fee", amount=1000000, case_type="财产案件")`
- 返回 `fee=13800`（按诉讼费用交纳办法第十三条分段累计）
- 附条文依据

### 12. 上诉期计算

```text
判决书 2026 年 11 月 6 日送达，上诉期到哪天？
```

期望：

- `legal_calculator(action="deadline", start_date="2026-11-06", days=15, deadline_type="appeal_judgment")`
- 返回 `end_date="2026-11-23"`（原届满 11-21 周六，顺延到周一）
- 说明“送达日当天不计入”

## 如果不符合预期

1. 先判断是“模型没调工具”还是“工具返回错”。
2. 模型没调工具：改工具 description 的“何时用”，再重测，记录前后对比。
3. 工具返回错：记录完整参数和返回，回到代码补测试，不要只改 prompt。
4. 第 7 条如果调用了工具，优先检查 `search_law` 的描述是否让模型误以为“任何法律概念都要查条文”。
